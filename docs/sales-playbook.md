# Sales Playbook

## Target Customers

- E-commerce with WhatsApp support bots
- SaaS companies deploying AI agents
- Agencies building chatbot solutions for clients
- Customer success teams scaling automated support

## Discovery Questions

1. How many conversations does your agent handle daily?
2. What happens when the agent gives wrong info?
3. Do you test before deploying prompt changes?
4. How do you measure agent quality today?

## Demo Flow (15 min)

1. **Landing** — show value prop (2 min)
2. **Login** — demo@pizzariaflow.com.br (instant)
3. **Dashboard** — risk overview, recent sims (3 min)
4. **Flows** — show pizza order flow with 6 steps (3 min)
5. **Simulation replay** — show failure on address step (4 min)
6. **Reports + Export** — Pro feature upsell (2 min)
7. **Pricing** — recommend Pro for growing teams (1 min)

## Objection Handling

| Objection | Response |
|-----------|----------|
| "We test manually" | Manual testing doesn't scale. FlowSentinel runs 500 sims/month on Pro. |
| "Our agent is simple" | Simple agents fail on edge cases — personas like "Cliente Reclamão" find them. |
| "Too expensive" | One bad customer interaction costs more than R$ 199/mês. |
| "We use ChatGPT evals" | FlowSentinel is conversation-flow aware with step-level risk weights. |

## Upsell Triggers

- Hit simulation limit → Pro
- Need export for compliance → Pro
- Multiple clients/agencies → Business
- Need automations on deploy → Pro/Business
